TEKNOLOGI UTAMA

Teknologi yang Digunakan

AIRA dibangun menggunakan teknologi terkini yang telah terbukti andal dalam berbagai penelitian dan implementasi sistem peringatan dini.

Computer Vision

YOLOv10 untuk deteksi genangan dan perubahan kondisi air pada CCTV.

YOLOv10 OpenCV Python

Time-Series AI

LSTM untuk analisis tren tinggi muka air dan curah hujan.

LSTM PyTorch Scikit-learn

Geospasial (GIS)

Visualisasi peta, analisis wilayah rawan, dan spasial data.

Leaflet PostGIS QGIS

IoT & Edge Computing

Sensor tinggi muka air, rain gauge, dan perangkat IoT dengan koneksi real-time.

ESP32 LoRa/4G MQTT

Data Cuaca

Integrasi API data cuaca untuk prediksi dan analisis risiko banjir.

OpenWeather BMKG API

Backend & API

Backend services untuk pengelolaan data dan analitik.

FastAPI Docker PostgreSQL

Frontend Dashboard

Dashboard interaktif dengan peta dan visualisasi real-time.

Vue.js TailwindCSS Chart.js

Notifikasi & Integrasi

Multi-channel notification (WhatsApp, Email, Siren) dan integrasi sistem lain.

WhatsApp API Email Webhook
